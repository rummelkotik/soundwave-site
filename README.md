# 🎧 Soundwave Showcase Landing

> Высокопроизводительный адаптивный промо-лендинг с модульной архитектурой, кастомным слайдером и автоматической оптимизацией медиа-ассетов.

🔗 **Live Demo:** [soundwave-site-steel.vercel.app](https://soundwave-site-steel.vercel.app)

---

## 📌 Ключевые инженерные решения

- ⚡ **Сборка на Vite:** Мгновенный Hot Module Replacement (HMR) в разработке и легковесный оптимизированный production-бандл.
- 🖼 **WebP Asset Pipeline:** Реализован скрипт предварительной обработки графики (`build-images.js`), обеспечивающий автоматическую конвертацию изображений в современный формат WebP для минимизации веса страницы и ускорения First Contentful Paint (FCP).
- 🎠 **Кастомный карусельный движок:** Бесшовная прокрутка баннеров и промо-блоков без лишних тяжелых библиотек, с корректным позиционированием и плавной динамикой на тач-устройствах.
- 📱 **Pixel-Perfect & Adaptive:** Полная кроссбраузерная адаптивность под любые разрешения экранов — от мобильных телефонов (320px) до десктопных мониторов высокой четкости.
- 🧹 **Чистая архитектура стилей:** Модульная организация CSS-файлов с изоляцией базовых компонентов и поддержкой прелоадов критических ресурсов в HTML.

---

## 🛠 Технологический стек

- **Языки:** JavaScript (ES6+), HTML5, CSS3
- **Инструменты сборки:** Vite
- **Оптимизация:** Автоматизированная генерация WebP через кастомные Node.js билд-скрипты
- **Деплой:** Vercel
